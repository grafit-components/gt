Компонент выбора

ItskSelectComponent

Выпадающий список для выбора одного или нескольких значений из набора данных. Реализует ControlValueAccessor, поэтому работает с ngModel и реактивными формами. Поддерживает поиск, кнопку очистки, кастомные шаблоны и навигацию с клавиатуры.

Базовое использование

Передайте массив данных в items и привяжите выбранное значение через ngModel. Параметр valueRef указывает, какое поле объекта использовать в качестве значения модели, а textRef — какое поле выводить в списке. Чтобы включить поиск, задайте searchRef, а для кнопки очистки — showClearButton: 

<itsk-select
  [items]="items"
  [(ngModel)]="selectedValue"
  valueRef="value"
  textRef="label"
  searchRef="label"
  showClearButton="true"
/>
Множественный выбор

Установите multiple="true" — в модель будет записываться массив значений. Параметр selectedRef="block" отображает выбранные элементы в виде отдельных блоков (чипсов).

Важно: режим multiple нельзя менять после инициализации компонента — это вызовет ошибку.

Значение модели и valueRef

Параметр valueRef определяет, что именно записывается в модель при выборе. Это может быть имя поля или функция, которая принимает элемент данных и возвращает значение. По умолчанию valueRef возвращает сам объект элемента целиком. 

// записывать в модель поле value
valueRef="value"

// или произвольное вычисляемое значение
[valueRef]="getId"     // getId = (item) => item.id

Поддерживается доступ к вложенным полям через точку, например valueRef="data.id". То же относится к textRef и searchRef. При изменении массива items выбранное значение перевычисляется автоматически по текущему valueRef.

Placeholder и блокировка

Параметр placeholder задаёт текст (или шаблон), который отображается, пока ничего не выбрано. Параметр disabled блокирует селект — открыть список и изменить значение нельзя. При работе через реактивные формы блокировка управляется состоянием контрола (FormControl.disable()).

Кастомный шаблон

Помимо строкового имени поля textRef может принимать TemplateRef — тогда вы полностью управляете разметкой элемента. Один и тот же шаблон используется и для строк выпадающего списка, и для отображения выбранного значения. Контекст шаблона содержит элемент данных в переменной item: 

<itsk-select [items]="items" [(ngModel)]="selectedValue" valueRef="id" [textRef]="userTpl" searchRef="name" />

<ng-template #userTpl let-item="item">
  <b>{{ '{{' }} item.name {{ '}}' }}</b> — {{ '{{' }} item.role {{ '}}' }}
</ng-template>
Поиск и виртуальный скролл

Задайте searchRef (имя поля или функцию) — над списком появится поле поиска с фильтрацией по подстрокам (без учёта порядка слов, без учёта регистра). При больших списках включите virtual="true" для виртуального скролла; высоту строки и области прокрутки регулируют itemSize и height.

Высота выпадающего списка подстраивается под количество элементов и ограничена восемью видимыми строками — далее появляется прокрутка.

Программное управление

Открыть или закрыть список программно можно через методы компонента open(), close() и toggle() — например, по ссылке на экземпляр через шаблонную переменную. Входной параметр panelOpen также позволяет задать состояние списка через привязку [panelOpen]="isOpen". 

<itsk-select #sel [items]="items" ... />
<button (click)="sel.toggle()">Переключить</button>
Клавиатура

Селект полностью управляется с клавиатуры:

Клавиша Действие
↑ / ↓ Открыть список и перемещать фокус по элементам
Enter / Space Выбрать элемент в фокусе (или первый результат поиска)
Shift + ↑/↓ Выбор элементов при перемещении (для multiple)
Esc Закрыть список
Любой символ Начать поиск (если задан searchRef)
API
ItskSelectComponent
Параметр Тип По умолчанию Описание
items any[] [] Данные для отображения
valueRef string | ((item) => any) (item) => item Поле или функция, возвращающие значение для модели
textRef string | TemplateRef — Поле или шаблон для отображения элемента
searchRef string | ((item) => string) — Поле или функция для поиска (включает поле ввода)
multiple boolean false Множественный выбор (нельзя менять после инициализации)
selectedRef TemplateRef | 'block' — Шаблон выбранного значения или режим блоков
placeholder string | TemplateRef — Текст или шаблон при отсутствии выбора
showClearButton boolean false Показывать кнопку очистки значения
disabled boolean false Заблокировать селект
virtual boolean false Использовать виртуальный скролл
itemSize number 32 Высота строки списка в px
height number itemSize * 8 Максимальная высота области прокрутки
panelOpen boolean false Управление состоянием открытия списка
