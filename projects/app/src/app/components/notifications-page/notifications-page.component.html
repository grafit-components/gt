Сервис уведомлений

GtNotificationService

Сервис для создания и управления уведомлениями. Уведомления отображаются в верхней части экрана и автоматически скрываются через заданное время.

Подключение

Сервис GtNotificationService предоставляется в корневом инжекторе и готов к использованию. Для создания уведомления используйте метод add():

Уровни уведомлений

Уведомления поддерживают 4 уровня. Уровень определяет цвет акцента и иконку уведомления:

info success warn error
Длительность отображения

Параметр duration задаёт время отображения уведомления в секундах. По умолчанию — 10 секунд. Установите 0 для постоянного уведомления.

Кастомный компонент

В уведомление можно добавить кастомный компонент через параметр component.

Внутри кастомного компонента доступен GtNotificationRef через inject() — с его помощью компонент может управлять собственным уведомлением, например закрыть его по завершении операции:

Чтобы передать в компонент собственные зависимости, используйте параметр injector — указанный инжектор станет родительским для DI кастомного компонента.

Иконки

Для отображения иконки используйте параметры iconName (имя иконки) и iconClass (дополнительные CSS-классы). Иконка отображается перед заголовком уведомления.

injector Injector — Инжектор для кастомного компонента
